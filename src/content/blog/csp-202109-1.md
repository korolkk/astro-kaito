## 题目
【题目描述】

【输入格式】
从标准输入读入数据。
输入的第一行包含一个正整数 n.
输入的第二行包含 n 个用空格分隔的自然数B1,B2,···,Bn
【输出格式】
输出到标准输出。
输出共两行。
第一行输出一个整数，表示sum的最大值。
第二行输出一个整数，表示sum的最小值。
【样例输入】

```
6
0 0 5 5 10 10
```

【样例输出】
```
30
15
```

## 代码
```cpp
#include<iostream>
using namespace std;

int main()
{
    int sum_max,sum_min;
    int n,pre,cur;
    cin>>n;
    pre=-1;
    sum_max=0;
    sum_min=0;
    for(int i=0;i<n;i++)
    {
        cin>>cur;
        if(cur!=pre)
        {
            sum_min+=cur;
        }
        sum_max+=cur;
        pre=cur;
    }
    cout<<sum_max<<endl<<sum_min<<endl;
    return 0;
}
```
