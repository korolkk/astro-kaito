## 题目

【题目背景】 2020年6月8日，国务院联防联控机制发布《关于加快推进新冠病毒核酸检测的实施意见》，提出对“密切接触者”等八类重点人群“应检尽检”，其他人群“愿检尽检”。 

【问题描述】 某市设有n个核酸检测点，编号从1到n,其中i号检测点的位置可以表示为一个平面整数坐标(xi,yi) 为方便预约核酸检测，请根据市民所在位置(X,Y),查询距其最近的三个检测点。 多个检测点距离相同时，编号较小的视为更近。 

【输入格式】 输入共n+1行。 第一行包含用空格分隔的三个整数n、X和Y,表示检测点总数和市民所在位置。 第二行到第n+1行依次输入n个检测点的坐标。第i+1行(1≤i≤n)包含用空格分隔的两个整数：xi和yi,表示 i号检测点所在位置。 

【输出格式】 输出共三行，按距离从近到远，依次输出距离该市民最近的三个检测点编号。 

【样例输入1】

```
3 2 2
2 2
2 3
2 4
```

【样例输出1】

```
1
2
3
```

## 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N=205;

struct dist
{
    int id;
    double d;
}a[N];

bool cmp(dist A,dist B)
{
    if(A.d==B.d)
        return A.id<B.id;
    return A.d<B.d;
}

int main()
{
    int n,X,Y,xi,yi;
    cin>>n>>X>>Y;
    for(int i=0;i<n;i++)
    {
        cin>>xi>>yi;
        a[i].id=i+1;
        a[i].d=pow(xi-X,2)+pow(yi-Y,2);
    }
    sort(a,a+n,cmp);
    cout<<a[0].id<<endl<<a[1].id<<endl<<a[2].id<<endl;
    return 0;
}
```
